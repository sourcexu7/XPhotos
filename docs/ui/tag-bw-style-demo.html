问题：饱和蓝实底在黑白灰版面上是唯一的强彩色块，视觉权重高于图片本身。

方案 1 · 反白实底 与主按钮同语言

浅色=黑底白字，深色=白底黑字（--primary 令牌同源）。对比度约 19:1（AAA），视觉最重，适合标签数量少（≤5 个）时当"可点入口"强调。

选择建议

- 想让标签完全隐入灰阶体系：选 方案 2（Unsplash 式）
- 想要安静默认 + 明确可点反馈：选 方案 4（个人站作品集最常见取向）
- 想让标签像次级按钮、数量少：选 方案 1 或 方案 5
- 想要极简幽灵 chip：选 方案 3
所有方案色值全部来自白瓷令牌（--primary / --muted / --border / --muted-foreground），改主题无需改标签代码；TagLink 的键盘可达性（tabIndex / role / Enter-Space）不受影响。
